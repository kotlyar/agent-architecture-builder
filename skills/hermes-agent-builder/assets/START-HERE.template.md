# Начните здесь

Этот комплект содержит полное задание на реализацию системы `{system_name}`.
Codex и Hermes автоматически прочитают корневой `AGENTS.md`; подробное задание
находится в `IMPLEMENTATION.md`.

## Состояние

Откройте `manifest.json`. Передавать комплект на реализацию можно только при
значении `готов_к_реализации` и пустом списке `critical_unknowns`.

## Codex

1. Распакуйте архив и откройте полученный каталог как проект.
2. Отправьте агенту:

> Прочитай `IMPLEMENTATION.md` и реализуй весь комплект до прохождения критериев
> приёмки. Не ограничивайся описанием или заготовками.

## Hermes

1. Распакуйте архив и запустите Hermes в полученном каталоге.
2. Отправьте ту же инструкцию.
3. После реализации установите созданные дистрибутивы профилей по инструкции из
   `implementation/IMPLEMENTATION-RESULT.md`.

## Важное ограничение

Реализация не разрешает расходовать деньги, публиковать, писать людям, менять
настоящие кабинеты или включать задания по расписанию без отдельного точного
подтверждения.
