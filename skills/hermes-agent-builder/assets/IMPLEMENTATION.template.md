# Реализация агентной системы

Реализуй систему, описанную в этом каталоге, до прохождения всех критериев
приёмки.

## Обязательный порядок

1. Прочитай `manifest.json`, `requirements/`, `architecture/`, `acceptance/`,
   `blueprint/`, `evidence/sources.md` и `unresolved.md`.
2. Убедись, что состояние равно `готов_к_реализации`, а список
   `critical_unknowns` пуст. Иначе прекрати реализацию, сохрани полезный разбор и
   назови один вопрос, без которого продолжать нельзя.
3. Создай результат в `implementation/`. Не изменяй исходные требования так,
   чтобы скрыть несоответствие.
4. Реализуй все предусмотренные части: профили Hermes, навыки, инструменты,
   процессы, хранилище, сервер и панель управления. Не добавляй части, которые
   архитектура отвергла.
5. Используй бесплатные библиотеки с открытым исходным кодом, зафиксированные в
   архитектуре. Повторно проверь их версии и лицензии.
6. Не записывай настоящие ключи, пароли, память, сеансы или рабочие данные в
   проект. Создай только файлы примеров переменных окружения.
7. Не совершай внешние изменения и не включай задания по расписанию без
   отдельного точного подтверждения пользователя.
8. Выполни автоматические и сквозные проверки из `acceptance/`. Исправляй
   найденные несоответствия, пока проверки не пройдут или не возникнет
   доказанный внешний блокер.
9. Создай `implementation/IMPLEMENTATION-RESULT.md`: состав реализации, команды
   установки и запуска, результаты проверок, известные ограничения, требуемые
   ключи и точные следующие действия человека.

Не заканчивай ответ проектом, рекомендациями или перечнем файлов. Завершённый
результат — работающий код, проверяемые дистрибутивы Hermes, пройденные проверки
и инструкция запуска.
