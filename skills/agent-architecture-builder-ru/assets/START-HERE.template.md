# Начало работы

Этот комплект содержит полное задание реализации для `{system_name}`. Основное
задание находится в `IMPLEMENTATION.md`, а соответствия платформ — в `platforms/`.

Открой `manifest.json`. Передавай комплект реализующему агенту только при
состоянии `ready_for_implementation`, `schema_version: 4` и пустом
`critical_unknowns`.

Отправь в Codex, Claude Code, Hermes или другой выбранной среде:

> Прочитай `IMPLEMENTATION.md` и реализуй весь комплект до прохождения критериев
> приёмки. Сохрани независимую от платформы архитектуру и примени только выбранные
> адаптеры. Реализуй обязательную проверку готовности и не разрешай предметную
> работу до настройки зависимостей.

Реализация не разрешает расходы, публикацию, сообщения, изменение рабочих
учётных записей, удаление или внешние действия по расписанию без отдельного
точного подтверждения.
